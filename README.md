# Creator Workbench · 自媒体工作台

在本机完成视频字幕、配乐与合成，再用 AI 生成平台文案和横竖封面。一套界面整理从原始视频到发布素材的流程。

项目采用原生 Node.js 与浏览器界面，FFmpeg 负责媒体处理，faster-whisper 负责本地语音识别。默认仅监听 `127.0.0.1`，通过浏览器访问，主要面向 Windows 桌面使用。

> 字幕识别和视频合成在本地运行，不需要 API Key。AI 章节、文案和封面需要自行配置第三方服务，可能产生费用；使用时会将文稿、创作方向及相关提示词发送至所配置的服务。仓库不附带 API Key、个人素材或模型权重。

## 功能

| 模块 | 支持内容 |
| --- | --- |
| 项目管理 | 导入或拖入视频、多项目切换、自动保存、删除项目 |
| 字幕识别与校对 | 本地 Whisper 时间戳识别、导入 SRT、逐句编辑文字与时间、下载当前字幕 |
| 字幕样式 | 字号、颜色、描边、断行、底部边距、圆角背景及透明度；预览与导出共用字幕图层 |
| 章节调整 | 根据带时间戳文稿由 LLM 划分章节，编辑名称与起止时间；在进度条上方按时段比例显示名称和分割线，预览与合成一致 |
| 视频进度条 | 随视频时长变化的进度条，可设置高度、边距、前景与底轨颜色、透明度 |
| 背景音乐 | 音乐库导入、试听、复用；循环配乐、音量、淡入淡出、讲话时压低配乐 |
| 视频合成 | FFmpeg 导出 MP4（H.264 / AAC），保留原比例，可选分辨率及 kbps 目标码率 |
| 平台文案 | 为抖音、视频号、小红书、B站生成标题、简介、话题及备选标题，支持编辑、复制和下载 |
| 横竖封面 | LLM 统一策划两版提示词，再分别生图；每版独立设置尺寸与比例、编辑提示词、单张重试 |
| 处理预设 | 保存、查看、应用、设为默认、删除；同时保存处理参数及配乐选择 |
| 导出记录 | 保留不同次合成和生图的结果，支持筛选、预览、下载、删除 |
| 提示词日志 | 按项目查看文案、封面策划、生图的实际请求、LLM 回复、耗时、状态和失败原因 |
| 导出项目 | 将最新成功视频、当前字幕、四平台文案及横竖封面打包成 ZIP，并附导出清单 |

### 一键处理

```text
导入视频
   ↓
复用已有文稿，或先完成本地 Whisper 识别
   ↓
   ├─ 平台文案生成
   ├─ 封面统一策划 → 横版图片 / 竖版图片并行生成
   └─ 章节推断（开启且尚无章节时）→ 视频合成 → 完成后即可下载
```

文稿准备完成后，文案、封面与视频处理线路并行进行。开启章节且尚无章节时，视频线路先调用文案模型推断章节再合成；已有章节直接复用，关闭章节则直接合成。章节推断失败仍继续合成，并单独报告失败。每条任务线路独立显示状态，同类任务防止重复提交；单路失败会保留其他已成功结果。预览区保留合成进度、所有运行中任务及最近完成消息，封面或文案完成不会覆盖合成状态；已有成功视频的下载入口持续保留。完成反馈直接显示在任务区和对应模块中，不要求关闭弹窗，封面与文案完成也不会重建参数区或播放器。也可以单独使用识别、文案、封面或合成功能。

## 安装与启动

### 1. 准备环境

| 依赖 | 要求 |
| --- | --- |
| Node.js | 22 或更高版本 |
| FFmpeg / FFprobe | 加入 PATH；FFmpeg 需要包含 libass、libx264 和 AAC 编码支持 |
| Python | 仅本地语音识别需要；本项目已在 Python 3.13 环境使用，依赖见 `requirements-whisper.txt` |
| 浏览器 | 建议使用近期版本的 Edge 或 Chrome |

Windows 需使用包含微软雅黑的系统环境；当前字幕样式指定该字体。可先检查命令：

```powershell
node --version
ffmpeg -version
ffprobe -version
python --version
```

Node.js 可从 [官方网站](https://nodejs.org/) 安装，FFmpeg 可从 [官方下载入口](https://ffmpeg.org/download.html) 获取。安装后重新打开终端，确认上述命令可用。

### 2. 获取项目

```powershell
git clone https://github.com/wjy420/creator-workbench.git
cd creator-workbench
```

也可以从 GitHub 的 **Code → Download ZIP** 下载后解压。

当前 Node 服务没有第三方 npm 依赖，也没有前端构建步骤，可以直接启动。

### 3. 安装本地语音识别（可选）

需要自动识别字幕时，双击 **`安装本地语音.cmd`**。脚本会创建项目专用 `.venv`、安装 Python 依赖，并下载 Small 模型到 `data/models/`。

也可以在项目根目录手动运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-whisper.txt
.\.venv\Scripts\python.exe scripts\whisper_local.py --prepare --model small --cache data\models
```

首次下载模型需要联网。缓存完成后可离线识别，音轨不上传到语音服务。若只导入已有 SRT，可跳过语音安装。

### 4. 启动工作台

双击 **`启动工作台.cmd`**，脚本会在后台启动服务并打开浏览器。重复双击会打开已运行的工作台。

或在终端执行：

```powershell
npm start
```

浏览器打开：**http://127.0.0.1:8769**。

- 使用 `.cmd` 启动后，可双击 **`关闭工作台.cmd`** 关闭本项目服务及相关处理子进程。
- 使用 `npm start` 启动时，在对应终端按 `Ctrl+C` 停止服务。
- 启动日志位于 `data/logs/workbench-out.log`，错误日志位于 `data/logs/workbench-error.log`。

## 使用方法

1. **导入视频**：新建项目或将视频拖入工作台，导入时应用默认预设。
2. **准备字幕**：执行本地识别，或导入 SRT；在字幕编辑区校对文字和时间。视频没有音轨时可导入字幕。
3. **设置画面和配乐**：调整字幕，在字幕与进度条之间的「章节调整」中生成或编辑章节，再调整进度条，选择音乐，设置音量、淡入淡出和人声避让。常用组合可保存为预设。
4. **生成发布素材**：填入文案创作方向和封面方向，分别生成文案、封面；两种方向独立保存。云端功能需要先完成下方 API 配置。
5. **视频合成**：选择分辨率及码率，点击「视频合成」。成功提示中可以下载视频和字幕；只修改样式不会改变旧视频，需要重新合成。
6. **整理发布结果**：在导出记录中查看历史结果，或点击右上方「导出项目」打包最新结果。

也可以配置好参数后直接使用「一键处理」。已有字幕会复用，文案和两版封面会重新生成。

参数区按「画面与声音」「发布素材」分区。字幕、章节、进度条和配乐默认收起，点击标题或顶部快捷导航展开；收起时显示关键参数摘要，浏览器会记住展开状态。功能开关与展开操作独立。

### 章节调整

- 单独点击「本地识别字幕」只识别并保存字幕，不调用章节 LLM，也不修改已有章节。章节由「生成章节」按钮单独触发；未配置文案 API 时也可手动添加章节。
- 导入 SRT 或已有文稿可点击「生成章节」；该按钮也可重新推断章节，使用当前保存的完整文稿及时间戳。
- 「编辑章节与时间」支持修改章节名、开始和结束秒数，以及添加、删除章节。时间须在视频范围内，章节不能重叠；允许留出空白时段。
- 画面只显示章节名称和分割线，每个名称位于对应时段的中央，过长时按区间宽度压缩。章节文字与分割线的中心保持在同一水平线上；可在「位置与分割线」中调整分割线长度、粗细及整体垂直偏移（源视频像素）。垂直偏移以进度条上沿为基准，正值上移、负值下移，两者同步移动。字号、颜色、显示开关及这些参数均随项目及预设保存。
- 章节生成中保存的编辑不会被异步结果覆盖。字幕校对后已有章节不会自动重写，可按需重新生成。
- 预览和导出使用相同章节图层；编辑完成须重新合成才会更新导出视频。项目 ZIP 包包含已保存的「章节.json」。

### 分辨率与码率

- 视频支持 `480p`、`720p`、`1080p`、`2K`、`原画`，默认 `1080p`、`3000 kbps`。
- 前四项分别将**短边**缩放到 480、720、1080、1440 像素，保持原比例，允许放大；H.264 输出尺寸取最近偶数。
- 原画保持源尺寸，奇数像素可能有不足 2 像素的偶数舍入。
- 码率以 **kbps** 输入，例如 `3000 kbps = 3 Mbps`。页面展示 FFprobe 测得的源视频与最近导出码率，音频和封装会增加总码率。

### 横竖封面

- 每版支持 `1K / 2K / 4K` 和 `16:9 / 9:16 / 4:3 / 3:4 / 1:1`。
- 默认横版 `1280×720`，竖版 `720×1280`；界面显示实际请求尺寸与返回尺寸。
- 「生成封面」重新策划并生成两张独立图片，共用视觉规范；模型生成的细节仍可能有差异。
- 图下的「重新生成」使用该版已保存或当前编辑的提示词及方案尺寸，不再次调用策划 LLM。
- 一张失败时，另一张成功结果保留，可以单独重试。图片分辨率支持取决于所选服务和模型，不保证服务原生输出全部尺寸。

## API 接入

打开左下角 **「设置与 API」**。文案模型与图片模型分别配置，密钥只需保存一次；刷新或重启后继续使用，密钥输入框留空会保留已有值。

### 文案与封面策划：DeepSeek / Chat Completions 兼容服务

| 设置项 | 填写方法 |
| --- | --- |
| API 地址 | DeepSeek 可填 `https://api.deepseek.com`；其他服务填写其 Chat Completions 基础地址，按需包含 `/v1` |
| 模型名称 | 填写账号可用的模型 ID；项目初始默认值为 `deepseek-flash` |
| API Key | 在对应服务控制台创建，填入输入框后保存 |

程序会在基础地址后追加 **`/chat/completions`**，使用 `Authorization: Bearer <API_KEY>` 鉴权。例如地址填 `https://api.deepseek.com`，最终请求就是 `https://api.deepseek.com/chat/completions`。**不要将完整端点填到 API 地址中**，否则会重复拼接路径。

接口需要支持：

- `model`、`messages`、`stream: false`；
- `response_format: { "type": "json_object" }`；
- 在 `choices[0].message.content` 中返回符合提示词结构的 JSON 文本。

同一文案服务用于章节推断、四平台文案及横竖封面提示词策划。因此，**完整封面生成需要同时配置文案 API 和图片 API**。

DeepSeek 的地址、密钥申请入口和当前模型名称见 [官方接入文档](https://api-docs.deepseek.com/)。其他服务即使声明接口兼容，仍需确认 JSON 输出和响应结构满足上述要求。

### 图片：云雾 / Images Generations 兼容服务

| 设置项 | 填写方法 |
| --- | --- |
| API 地址 | 项目初始默认值为 `https://yunwu.org/v1`，也可改为其他兼容服务的基础地址 |
| 模型名称 | 填写提供方控制台中可用的生图模型 ID；代码初始值为 `gpt-image-2.5-flare-c`，不代表任意账号均可用 |
| API Key | 填写该图片服务提供的密钥，可以与文案服务使用不同的 Key |

程序在地址后追加 **`/images/generations`**，使用 Bearer 鉴权。请求体结构如下，示例不包含密钥：

```json
{
  "model": "YOUR_IMAGE_MODEL_ID",
  "prompt": "本次封面的完整生图提示词",
  "size": "1280x720",
  "n": 1
}
```

服务需要支持 `size` 的像素字符串，并在 `data[0]` 中返回 `b64_json` 或可由本机服务下载的 `url`。程序会下载图片并探测真实尺寸，不会将较小返回图标称为原生高分辨率。

仅提供异步任务 ID、Responses 接口或图片编辑接口的服务，不能直接接入当前实现。若出现尺寸不支持、模型不存在或参数不兼容，请改用提供方支持的模型与尺寸。

### 本地 Whisper：不需要 API Key

「设置与 API」中可选择：

- 模型：Tiny、Base、Small、Medium、Large v3、Turbo；
- 设备：自动、CPU、NVIDIA GPU；
- 语言：中文、英文、自动检测。

自动模式在运行库齐全时使用 GPU，否则使用 CPU int8。强制 GPU 时需要可用的 CUDA / cuDNN 运行库，缺失会报错。本地识别串行排队；首次切换到未缓存模型时需要下载。

### 调用次数与日志

- 单次章节推断：1 次 LLM 请求。手动生成与一键处理使用相同服务。
- 单次平台文案生成：1 次 LLM 请求。
- 完整封面生成：1 次 LLM 策划请求，加 2 次图片请求；策划校验失败时不继续生图。
- 单张封面重试：1 次图片请求。
- 一键处理在需要生成文案和两版封面时包含 2 次 LLM 与 2 次图片请求；开启且尚无章节时额外调用 1 次章节 LLM，按所选服务规则计费。

章节、文案和封面区的「提示词日志」可以检查实际请求、模型回复、HTTP 状态和错误。日志不记录鉴权头，并对已知密钥脱敏。模型返回结构错误时，应结合任务提示和最终输出排查。

## 数据与密钥

运行后默认在本地生成：

```text
data/
├─ workspace.json        # 项目、预设和 API 配置，含明文密钥
├─ models/               # Whisper 模型缓存
├─ music/                # 独立音乐库
├─ logs/                 # 启动日志
├─ project-bundles/      # 项目结果临时 ZIP
└─ <项目 ID>/            # 素材、字幕、文案、封面、视频与提示词日志
```

- **不要分享或提交 `data/workspace.json`、其备份或整个 `data/` 目录。密钥是本机明文存储，没有加密。**
- 仓库通过 `.gitignore` 排除 `data/`、`.venv/`、`.env` 类文件、日志和私钥文件。忽略规则不会自动清除已经提交过的敏感文件，提交前仍应检查暂存区。
- 本项目不从 `.env` 自动加载 API Key，也不支持通过 `DEEPSEEK_API_KEY` 等环境变量直接配置应用密钥；请使用界面保存。
- 项目 ZIP 只包含最新发布结果及清单，不含源素材、历史结果或 API 配置。尚未生成的部分会跳过并写入清单。
- 关闭服务不会删除项目；删除项目会清理其素材及结果，独立音乐库保留。
- 本地服务没有面向公网的用户登录体系，请按本机应用使用。

## 高级配置

下列环境变量用于直接运行 `node server.mjs` 或测试。Windows 双击启动脚本会自行设置默认端口和数据目录。

| 变量 | 默认值 / 用途 |
| --- | --- |
| `PORT` | `8769`，HTTP 端口 |
| `DATA_DIR` | 项目根目录下的 `data`，建议自定义时填绝对路径 |

```powershell
$env:PORT = '8779'
node server.mjs
```

## 常见问题与限制

- **找不到 FFmpeg / FFprobe**：确认两者均已加入 PATH；安装后重新启动终端和工作台。
- **识别环境未就绪**：先运行语音安装脚本，检查 `.venv` 和模型缓存。首次下载需要访问模型源；没有 NVIDIA 环境可选 CPU。
- **API 返回 401 / 403、模型或额度错误**：确认密钥属于当前服务、模型 ID 正确且账号有权限及额度。
- **API 返回 404 或非 JSON**：检查基础地址，不要重复填写 `/chat/completions` 或 `/images/generations`。
- **图片未按所选尺寸输出**：查看图下实际像素及日志；目标尺寸能否原生生成取决于提供方。
- **浏览器不能预览某些源视频**：浏览器可能不支持该编码，FFmpeg 仍可能处理；必要时先转为浏览器支持的格式。
- **字幕改了但下载视频没变**：需要重新合成；旧视频不会随参数编辑自动更新。
- **配乐试听与最终效果略有差别**：实时试听为近似混音，最终人声避让以 FFmpeg 导出为准。
- **运行中重启会怎样**：任务状态保存在内存，未完成任务不跨重启恢复；已保存的项目和成功结果保留。
- 当前未提供批量任务、任务取消和自由填写导出分辨率。Windows 启停脚本及微软雅黑字体依赖尚未适配为通用跨平台方案。
